# Фітнес-дашборд

Особистий застосунок для iPhone: заміри InBody (фото чека з розпізнаванням цифр прямо на телефоні), журнал тренувань із шаблонами full-body, прогрес сили, баланс навантаження по групах м'язів. Дизайн у стилі iOS Liquid Glass.

Усі дані зберігаються **тільки на телефоні** (IndexedDB). Серверу немає.

**Відкрити:** https://grabych-jr3.github.io/fitness-dashboard/

## Встановлення на iPhone

1. Відкрий посилання вище в **Safari** (саме в Safari, не в Chrome).
2. Натисни «Поділитися» (квадрат зі стрілкою) → **«На початковий екран»** → «Додати».
3. Запускай з іконки на початковому екрані: застосунок відкривається на весь екран і працює без інтернету.
4. Оновлення підтягуються самі при наступному запуску з інтернетом.

> Перше розпізнавання чека завантажує ~7 МБ файлів розпізнавання, потрібен інтернет. Далі все працює офлайн.

## Розпізнавання чека через Gemini (рекомендовано)

1. Відкрий https://aistudio.google.com/app/apikey і натисни «Create API key» (безкоштовно, без картки).
2. У застосунку: **Налаштування → Розпізнавання чека (Gemini)** → встав ключ → «Зберегти» (ключ одразу перевіряється).
3. Тепер фото чека читає Gemini; якщо він недоступний (немає інтернету, вичерпано ліміт) — автоматично спрацьовує звичайне розпізнавання на телефоні.

Ключ зберігається тільки на телефоні, у бекап і в репозиторій не потрапляє. На безкоштовному тарифі Google може використовувати надіслані фото для покращення моделей.

## Як фотографувати чек

- Поклади чек рівно на темну однотонну поверхню, без згинів.
- Світло рівне, без тіні від телефона; чек займає більшу частину кадру.
- Після розпізнавання перевір підсвічені поля — термочек інколи читається нечітко.

## Бекап

Дані живуть у застосунку на телефоні. Якщо видалити іконку з початкового екрана, вони зникнуть.

- **Налаштування → Бекап → Зберегти** — відкриється меню «Поділитися», обери «Зберегти у Файли» (iCloud Drive).
- **Відновити** — обери збережений файл `fitness-dashboard-РРРР-ММ-ДД.backup.json`. Поточні дані буде замінено.
- Якщо бекапу не було понад місяць, на «Огляді» з'явиться нагадування.

## Розробка

```bash
npm install
npm run dev      # http://localhost:5173/fitness-dashboard/
npm test         # Vitest
npm run build    # збірка в dist/
```

Стек: Vite + React + TypeScript, vite-plugin-pwa, Dexie (IndexedDB), Tesseract.js, Chart.js.
Кожен пуш у `main` проходить тести, збирається і деплоїться на GitHub Pages (`.github/workflows/deploy.yml`).

План і рішення — у [PLAN.md](PLAN.md).
